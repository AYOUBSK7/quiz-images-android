# Quiz en images (Android / Kotlin)

TP Android : quiz de 5 questions illustrées (thème : formes géométriques).

## Ouvrir et lancer
1. Cloner le dépôt : `git clone <lien-du-depot>`
2. Ouvrir le dossier avec Android Studio, attendre la synchronisation Gradle.
3. Choisir un émulateur ou un téléphone, puis cliquer sur Run ▶.

## Contenu du dépôt
- `app/` : code Kotlin (`MainActivity.kt`), layout XML, images (drawable)
- `captures/` : captures d'écran
- `compte-rendu/` : compte rendu du TP
